# Star Wave Radio 104.4 FM — App v1.0 Prototype

This is a mobile-first installable web app prototype for Star Wave Radio 104.4 FM.

## Included
- Home dashboard
- Listen Live screen
- Programme schedule
- News section
- WhatsApp song requests
- Advertising/contact section
- More/About section
- PWA manifest + offline shell

## Important live-stream note
The current listener address `https://mickierays.on-air.fm` is treated as the online stream page. For native in-app audio playback, replace the `audio.src` value in `index.html` with the station's **direct audio stream URL** (for example an HTTPS MP3/AAC stream URL supplied by the streaming provider).

## Use on Android
1. Extract the ZIP.
2. Open `index.html` in a browser for a quick preview.
3. To install as an app, host the folder on HTTPS, open it in Chrome, then choose **Add to Home screen / Install app**.

This package is the working UI prototype/source, not yet a signed Google Play APK.
